# Language

## Lexical structure

- **Comments**: `#` to end of line. `##` is a section comment by convention; the
  editor may show it as a frame title. A line holding only a comment belongs
  to the line break, so its indentation never opens or closes a block.
- **Identifiers**: `[A-Za-z_][A-Za-z0-9_]*`, except `True`, `False`, `None` and
  `_`. Node names may contain dots (`img.blur`) and may be prefixed by a `@use`
  alias (`g.entity`).
- **Keywords** (`True`, `False`, `None`, `_`, `as`) and **directives**
  (`@use`, `@def`, ...) end at a word boundary: `Nonesuch`, `_tmp` and `asg`
  are identifiers, and `@metax` is an error.
- **Reserved**: `True`, `False`, `None`, `_` (discard); builtins `branch`,
  `switch`, `jump`, `parallel`, `each`; the node prefix `kir.`; any name or
  label containing `__` (generated by optimization passes, see passes.md).
- **Literals** (Python syntax): int (decimal, hex, octal, binary; ASCII digits),
  float (finite: `1e999` is an error), bool, `None`, string (single, double,
  triple quoted), list, dict. `@meta` / `@hint` values may also be tuples:
  `()`, `(x,)`, `(x, y)`.
- **Labels**: backtick-quoted identifiers, `` `body` ``, naming namespaces.
- **Indentation**: 4 spaces per level; the first statement of a file is not
  indented. Inside `( )`, `[ ]`, `{ }` newlines are ignored, so calls and
  signatures may span lines.

## Statements

### Assignment

```
name = expression
name: Type = expression
```

`expression` is a literal or a name. Reassignment is allowed.

### Node call

```
(inputs)node_name(outputs)
```

- `inputs`: positional arguments, then keyword arguments (`key=value`). Each is
  a name or a literal.
- `outputs`: names to bind, `_` to discard. The count must equal the node's
  output count.

### Namespace

```
label:
    body
```

A labelled block. It is skipped when reached in sequence and entered only by
`branch`, `switch`, `jump`, `parallel`, `each` or `collect` (semantics.md).

### Builtins

All builtins use the node-call form; labels sit in the output list.

| Form | Meaning |
|---|---|
| ``(cond)branch(`t`, `f`)`` | enter `t` if `cond` is `True`, else `f` |
| ``(value)switch(1=>`a`, 2=>`b`, _=>`other`)`` | enter the label whose case equals `value`; `_` is the default |
| ``()jump(`label`)`` | transfer control to `label` |
| ``()parallel(`a`, `b`, ...)`` | enter every label; no order between them |
| ``(items)each(item, `body`)`` | enter `body` once per element of `items`, bound to `item` |
| ``(items)each(item, index, `body`)`` | the same, also binding the 0-based `index` |
| ``(items)collect(item, `body`, value -> results)`` | collect the value read at each normal body completion; publish ordered `results` only on success |
| ``(items)collect(item, index, `body`, value -> results)`` | the same, also binding the 0-based `index` |

The collection result input is deferred, not read on entry. See [collect.md](collect.md)
for carried state, exception behavior, target/control restrictions and initial mutation safety.

### Directives

| Directive | Attaches to | Meaning |
|---|---|---|
| `@use "library"` / `@use "library" as alias` | file (top only) | make a node library's signatures available (signatures.md) |
| `@import "module.kir" as alias` | file preamble | import exported KIR implementations ([modules.md](modules.md)) |
| `@export name` | file preamble | export one top-level KIR definition ([modules.md](modules.md)) |
| `@def (params)name(outputs):` | — | define a subgraph |
| `@meta key=value ...` | next statement | editor data (ids, positions); never affects results |
| `@hint key=value ...` | next statement | scheduling hints for executors; never affects results |
| `@dataflow:` | block | statements ordered by data dependence only (stable topological order, passes.md) |
| `@try:` / `@except:` / `@except name:` | block pair | error handling (semantics.md) |
| `@typehint:` | block | signatures for nodes that have none: `(Image, Box)crop(Image)` |
| `@mode dataflow` | file (top only) | the whole file is one `@dataflow:` block; no control flow allowed |

### Subgraph definition

```
@def (image: Image, box: Box, budget: int = 8)expand(node: Node?):
    body
```

Parameters may carry a type and a default; outputs may carry a type. A
subgraph is called like any node.

### Types

```
Type := Name | Name "?" | Name "[" Type ("," Type)* "]" | Type "|" Type | "_"
```

`T?` is `T | None`; `_` is any type. Type names are nominal and opaque to KIR,
except the literal types `int`, `float`, `str`, `bool`, `None`, `list`,
`dict`. Nominal names may be dotted (`library.Token`); source-module qualification
and visibility are defined in [modules.md](modules.md).

## Grammar (EBNF)

```
program       = { use_decl | import_decl | export_decl } { statement } ;
use_decl      = "@use" STRING [ "as" IDENT ] NEWLINE ;
import_decl   = "@import" STRING "as" IDENT NEWLINE ;
export_decl   = "@export" IDENT NEWLINE ;
statement     = simple NEWLINE | compound ;
simple        = assignment | call | meta | hint | mode ;
compound      = namespace | subgraph | dataflow | try_block | typehint ;

assignment    = IDENT [ ":" type ] "=" expr ;
call          = "(" [ in_list ] ")" FUNC "(" [ out_list ] ")" ;
in_list       = in_item { "," in_item } [ "," ] ;
in_item       = expr | IDENT "=" expr ;
out_list      = out_item { "," out_item } [ "," ] ;
out_item      = IDENT | "_" | LABEL | expr "=>" LABEL | "_" "=>" LABEL | expr "->" IDENT ;

namespace     = IDENT ":" NEWLINE [ INDENT { statement } DEDENT ] ;
subgraph      = "@def" "(" [ params ] ")" IDENT "(" [ def_outs ] ")" ":" block ;
params        = param { "," param } [ "," ] ;
param         = IDENT [ ":" type ] [ "=" expr ] ;
def_outs      = IDENT [ ":" type ] { "," IDENT [ ":" type ] } [ "," ] ;
dataflow      = "@dataflow" ":" block ;
try_block     = "@try" ":" block "@except" [ IDENT ] ":" block ;
typehint      = "@typehint" ":" NEWLINE INDENT { "(" [ types ] ")" FUNC "(" [ types ] ")" NEWLINE } DEDENT ;
block         = NEWLINE INDENT { statement } DEDENT ;

meta          = "@meta" pair { pair } ;
hint          = "@hint" pair { pair } ;
pair          = IDENT "=" pair_value ;
pair_value    = literal | IDENT | tuple ;
tuple         = "(" ")" | "(" pair_value "," ")" | "(" pair_value { "," pair_value }+ [ "," ] ")" ;
mode          = "@mode" IDENT ;

expr          = literal | IDENT ;
type          = type_atom { "|" type_atom } ;
type_atom     = "_" | "None" | FUNC [ "?" ] | FUNC "[" type { "," type } "]" [ "?" ] ;
FUNC          = IDENT { "." IDENT } ;
LABEL         = "`" IDENT "`" ;
```

Every program v1 parses also parses under this grammar. The additions are `@use`,
`@hint`, `each`, typed `@def` parameters and outputs, generic types, and the
optional name after `@except`.
